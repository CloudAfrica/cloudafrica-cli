## ca support tickets resolve

Resolve a support ticket

### Synopsis

Marks the ticket resolved and answers with the ticket summary. A later reply reopens it.

```
ca support tickets resolve SUPPORT_TICKET [flags]
```

### Examples

```
  ca support tickets resolve 1234
```
