## ca bucket create

Order a new object storage bucket

### Synopsis

Orders one bucket; the bucket's name is generated by the platform and appears in the list once it exists. Requires write:s3. Must carry an Idempotency-Key header: a retry under the same key is answered with the first order's stored response rather than starting a second, and 409 while that first order is still in flight. Asynchronous: returns 202 with the operation to poll at Location. Refuses with 422 limit-reached at the account's bucket cap — a provisioning rejection, so its body carries the reason and a sentence but no limit figures.

```
ca bucket create [flags]
```

### Examples

```
  ca bucket create --display-name backups
  ca bucket create --display-name audit --object-lock --versioning enabled
```

### Options

```
  -d, --data string           the JSON request body: a literal, @file or @- (stdin); flags override its fields
      --display-name string   Customer-chosen display name (max 120).
  -h, --help                  help for create
      --no-wait               print the operation and return without waiting for it
      --object-lock           Enable S3 object lock. Write-once: a bucket ordered without it can never be locked afterwards.
      --timeout duration      how long to wait for the operation (default 10m0s)
      --versioning string     Versioning at creation, off / enabled / suspended; absent leaves Croit's default. (one of: off, enabled, suspended)
```
