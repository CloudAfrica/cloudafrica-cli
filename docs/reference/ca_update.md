## ca update

Update ca to the latest release

### Synopsis

Update ca to the latest release on GitHub, after checking the download against the release's SHA256SUMS.
A ca installed with Homebrew or Scoop is updated by that package manager; ca names the command.

```
ca update [flags]
```

### Options

```
      --check   only report whether a newer release exists
  -h, --help    help for update
```
