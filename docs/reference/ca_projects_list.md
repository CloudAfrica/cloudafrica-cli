## ca projects list

List projects

### Synopsis

The account's projects, the default project first and then by name. Cursor-paginated: follow nextCursor via `?cursor=`.

```
ca projects list [flags]
```

### Options

```
      --cursor string   with --limit, the page to fetch (the previous page's nextCursor)
  -h, --help            help for list
      --limit int       fetch one page of at most this many rows (the route's cap applies) and print it as returned
```
